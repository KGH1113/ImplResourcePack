# ImplDmNote upstream provenance

ImplDmNote is a modified version of [DM Note](https://github.com/DmNote-App/DmNote).

- Upstream release: `1.6.1`
- Upstream commit: `167f7c8223d790f8d1240737293dba46bedf4753`

## Modifications

- Renamed and isolated the application as ImplDmNote.
- Assigned an independent bundle identifier and application data directory.
- Removed the upstream release/update channel.
- Added an ADOFAI-IPC client that synchronizes the active key-viewer profile with ImplResourcePack.

The complete GPLv3 license remains in `LICENSE`, and upstream third-party notices remain in
`THIRD_PARTY_NOTICES.txt`.
